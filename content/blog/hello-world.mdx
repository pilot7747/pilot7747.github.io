Welcome to my new website. I finally got around to building something that doesn't look like it was made in 2005.

## Why a blog?

Mostly because I've accumulated a bunch of notes and random thoughts that might be useful to someone else. Or might not. We'll see.

I work on large language models at JetBrains, specifically on code completion and generation. Before that, I spent a few years at Yandex working on crowdsourcing AI and RLHF.

## What to expect

I'll probably write about:

- **ML stuff** — training tricks, debugging distributed systems, things that break in production
- **Engineering** — tools, workflows, opinions about code
- **Random thoughts** — whatever seems interesting at the moment

## Tech stack

This site is built with:

```
Next.js + TypeScript + Tailwind CSS
```

Blog posts are written in MDX, which is basically Markdown with JSX support. The whole thing deploys to Vercel automatically.
