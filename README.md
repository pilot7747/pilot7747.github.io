# Personal Portfolio Website

This is my personal portfolio website built with Next.js and Tailwind CSS. The website showcases my professional experience, projects, publications, and contact information.

## Technologies Used

- **Next.js 15.2** - React framework with server-side rendering and app router
- **Tailwind CSS 4.0** - Utility-first CSS framework
- **Framer Motion** - Animation library
- **React Icons** - Icon library
- **Gray Matter, Remark** - Markdown processing

## Features

- Modern, responsive design
- Fast performance with server components and static generation
- Markdown content management
- Smooth animations and transitions
- SEO optimized
- Dark mode support

## Getting Started

### Prerequisites

- Node.js 18.17 or later

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/pilot7747/pilot7747.github.io.git
   cd pilot7747.github.io
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Deployment

The site is automatically deployed to GitHub Pages when changes are pushed to the main branch.

To build the production version locally:

```bash
npm run build
npm run start
```

## Content Management

Website content is stored in Markdown files in the `content` directory:

- `content/jobs/` - Work experience
- `content/projects/` - Projects information
- `content/img/` - Images and media
